# Post — The Plan Changes

**Status:** Posted
**Pillar:** Building in Public

---

Strength training requires adaptation. A shoulder starts hurting. A vacation gym only has dumbbells. Goals shift because life shifts. A good programme changes based on many different factors, some you can plan for and some you can't.

When I was coaching, I rebuilt plans constantly. I'd walk through the next weeks and months, figure out what still holds, what needs to change, how to keep progress going through whatever just happened or what we expected to happen. I could do it because I had the context. I knew the person. I knew their history.

Building Charles, adapting a plan was the thing I wanted to solve.

Charles generates a programme for the next four months. Then it regenerates every month based on every session log. The number of sets you did. The number of reps you did. Any pains you flagged during the month. The next phase gets built from that.

Before AI, adapting this way was hard to do in software. A rule-based system would have to anticipate every scenario someone could log. Every combination of reps, skipped sessions, flagged pains, missed weeks. A coach handles it by reading context. That is what AI changes. The system can read what happened and decide what to do without being told every possible path in advance.

I think this is where software is going. The version you have today keeps shifting based on what you actually did yesterday.

It moves with you.
