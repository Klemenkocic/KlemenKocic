# Post — They Built It. They Can't Control It.

**Status:** Posted
**Pillar:** Augmentation Thinking

---

We built a system at Luminous Group called Luminosity.

Thirty agents across five machines. Two years of running it now. The part we spent the most time on was figuring out where the humans need to stay, and how to keep them there as the agents take on more.

The pattern we ended up with is borrowed from older industries. Aviation, surgery, nuclear safety, financial risk. They figured out long ago that automation works best when humans are positioned to see what is happening while there is still time to act on it.

So we built three things into Luminosity. A way to see what an action will do before it commits. A way to notice when the system is drifting while it is still drifting. A way to surface what we already know about a similar past situation when a decision lands in front of us.

I think more agentic systems will need to be built this way. The agents take on more. The humans stay where they can actually see what is happening.
