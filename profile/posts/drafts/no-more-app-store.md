# Post — No More App Store

**Status:** Draft
**Pillar:** Augmentation Thinking

---

In my world, people are already saying things like "send this GitHub link to your agent and it will set everything up for you." It is becoming normal to let an agent pull a repository, configure the environment, and get things running without the user touching anything.

I know that is not everyone's reality yet. But I think it shows where things are going.

In the future, in my opinion, we may not have an app store the way we know it. You will not browse a store and click install. You will talk to something and it will find what you need, set it up, connect it to your tools, and let you use it. The whole layer of searching, downloading, and configuring disappears.

I think Apple sees this too. The infrastructure of how software is delivered is being reconsidered. The app store was designed for a world where people had to find and install software themselves. I do not think that world lasts forever.

This might sound controversial. But every major shift in how we interact with technology felt that way before it happened.
